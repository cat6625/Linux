# 三、馬王堆帛書《周易》卦序的研究重點

帛書系統最重要的地方，不只是「某一卦排在第幾位」，而是它顯示：

**今本六十四卦次序 ≠ 戰國至秦漢之間唯一存在的六十四卦次序。**

因此研究時應分成三層：

### 第一層：卦名

例如：

| 今本 | 帛書所見     | 研究意義             |
| -- | -------- | ---------------- |
| 乾  | 鍵        | 顯示早期文字、字形及卦名系統差異 |
| 坤  | 川        | 顯示「坤」卦名的異文系統     |
| 否  | 否／婦等異文問題 | 涉及卦名傳寫與字形解讀      |
| 咸  | 咸／欽等異文   | 顯示早期卦名異寫         |
| 謙  | 謙／兼      | 異體、通假及卦名傳承問題     |
| 履  | 履／禮等異文   | 卦名與傳世字形關係        |
| 大畜 | 大畜／大毒等異文 | 字形、音義與傳抄問題       |
| 革  | 革／勒      | 卦名異寫及古文字問題       |

# 四、今本與帛本的核心差異

| 比較項目 | 今本《周易》       | 馬王堆帛書《周易》      |
| ---- | ------------ | -------------- |
| 卦序   | 通行六十四卦次序     | 保存另一傳承系統       |
| 開端   | 乾、坤          | 鍵、川            |
| 編排形式 | 上經、下經        | 帛書自身編排形式       |
| 卦名   | 後世通行字形       | 保存大量早期異寫       |
| 經文   | 傳世文本         | 提供早期異文         |
| 《易傳》 | 與今本經文形成固定傳統  | 同墓出土多種《易傳》材料   |
| 思想層次 | 經傳合流後的成熟形態   | 可觀察經文及傳文不同形成層次 |
| 卦序意義 | 與《序卦》等傳統密切相關 | 顯示今本卦序並非唯一古代系統 |
| 研究價值 | 建立傳世《周易》基準   | 重建《周易》文本形成史    |

# 五、研究上最重要的「今本—帛本」對照框架

可以把兩者的差異概括成：

**今本：**

> 乾 → 坤 → 屯 → 蒙 → 需 → 訟 → 師 → 比 → …… → 既濟 → 未濟

其特色是形成一個完整、固定、具有敘事及《序卦》解釋傳統的六十四卦系統。

**帛本：**

> 以「鍵、川」等異寫保存早期文本形態，並以不同於今本的編聯、卦序與《易傳》材料，呈現另一條《周易》傳承線。

因此，不能簡化成：

> 「帛本就是今本的早期版本。」

較準確的表述應是：

> **帛書《周易》與今本《周易》是兩個具有親緣關係、但並非完全相同的文本傳承系統。帛書保存了今本以外的卦名、卦序、經文異文及《易傳》材料，因此可用來觀察《周易》由早期卜筮文本向戰國秦漢義理化、政治化及宇宙論化形態發展的過程。**
