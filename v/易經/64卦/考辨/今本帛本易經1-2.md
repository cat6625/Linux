# 今本與馬王堆帛本《周易》六十四卦卦序總表

## 一、卦序原理

### 1. 今本《周易》

今本六十四卦採「乾、坤、屯、蒙……既濟、未濟」次序，分為上經、下經：

> **乾 → 坤 → 屯 → 蒙 → 需 → 訟 → 師 → 比 → …… → 既濟 → 未濟**

此一系統的卦序，與《序卦傳》所形成的「相承、相因」敘事結構密切相關。

### 2. 馬王堆帛書《周易》

帛本不依今本「上經／下經」排列，而採八宮式結構：

**上卦（宮）順序：**

> 鍵（乾） → 根（艮） → 贛（坎） → 辰（震） → 川（坤） → 奪（兌） → 羅（離） → 筭（巽）

**每宮下卦順序：**

> 鍵（乾） → 川（坤） → 根（艮） → 奪（兌） → 贛（坎） → 羅（離） → 辰（震） → 筭（巽）

因此形成：

> **8 個上卦宮 × 8 個下卦 = 64 卦**

需要特別注意：這裡所說的「八宮」，是對帛書卦序結構的描述，**不能直接等同於後世京房八宮卦的世爻、游魂、歸魂體系**。

# 四、帛本卦序的「矩陣」結構

將兩個序列分開看，會非常清楚：

### 上卦／宮序

> **乾 → 艮 → 坎 → 震 → 坤 → 兌 → 離 → 巽**

帛書字形：

> **鍵 → 根 → 贛 → 辰 → 川 → 奪 → 羅 → 筭**

### 下卦序

> **乾 → 坤 → 艮 → 兌 → 坎 → 離 → 震 → 巽**

帛書字形：

> **鍵 → 川 → 根 → 奪 → 贛 → 羅 → 辰 → 筭**

所以帛本的基本生成方式可以表示為：

> **上卦序 × 下卦序 = 六十四別卦**

而不是：

> 今本第1卦 → 第2卦 → 第3卦 → …… → 第64卦

# 五、今本與帛本最重要的差異

| 項目     | 今本《周易》   | 馬王堆帛本《周易》      |
| ------ | -------- | -------------- |
| 六十四卦   | 64       | 64             |
| 起首     | 乾、坤      | 鍵（乾）           |
| 卦序     | 乾坤屯蒙……   | 八宮矩陣           |
| 分上下經   | **有**    | **不依上下經排列**    |
| 結構中心   | 卦與卦的承接關係 | 上下經卦的組合        |
| 上卦次序   | 非此種八宮排列  | 乾艮坎震坤兌離巽       |
| 下卦次序   | 非此種排列    | 乾坤艮兌坎離震巽       |
| 卦名     | 傳世字形     | 大量古文字／異寫       |
| 卦序思想   | 敘事、承接性強  | 分類、矩陣性強        |
| 後世《序卦》 | 與今本高度配合  | 不能直接套用         |
| 與京房八宮  | 不同       | **不能直接等同京房八宮** |

# 六、研究上最值得保留的三個觀察

### ① 帛本不是「今本卦序的另一種排列」

更準確的說法是：

> **今本與帛本保存了兩套不同的六十四卦組織方式。**

今本的核心特徵是：

> **卦—卦相承的序列**

帛本的核心特徵則是：

> **經卦—經卦相重的矩陣**

因此不能把帛本理解成「把今本六十四卦重新洗牌」。

---

### ② 「八宮」可以描述帛本，但不要直接套入京房八宮

帛本確實具有：

> **8 個上卦宮 × 每宮 8 卦**

的明顯結構。

但是後來京房易學的八宮，另有：

> 初爻變 → 二爻變 → 三爻變 → 四爻變 → 五爻變 → 游魂 → 歸魂

的爻變體系。

所以研究筆記最好寫成：

> **「帛書八宮式卦序」**

而不要直接寫：

> **「帛書即京房八宮」**

二者只是形式上具有「八組」的相似性，理論生成原理不能混同。

---

### ③ 帛本卦序與「八卦相錯」的思想值得一起研究

帛書《衷》保存有：

> 「天地定立（位），山澤通氣，火水相射，雷風相薄，八卦相錯」

一類文字，而帛本六十四卦正是把八個經卦彼此相重，形成六十四別卦。

因此後續研究可以把：

> **八卦 → 相錯 → 重卦 → 六十四卦**

與帛本卦序放在同一個框架中考察。

---

# 七、最簡潔的「帛本卦序公式」

最後可以把馬王堆帛本六十四卦壓縮成這個公式：

> **上卦：**
>
> 乾 → 艮 → 坎 → 震 → 坤 → 兌 → 離 → 巽
>
> **下卦：**
>
> 乾 → 坤 → 艮 → 兌 → 坎 → 離 → 震 → 巽
>
> **相重：**
>
> **8 × 8 = 64**

也就是：

> **乾艮坎震｜坤兌離巽**
>
> ×
>
> **乾坤艮兌｜坎離震巽**
>
> ＝
>
> **馬王堆帛書六十四卦卦序**

這才是後續建立「今本—帛本—京房八宮—先天方圓圖」比較表時最穩固的基礎。
