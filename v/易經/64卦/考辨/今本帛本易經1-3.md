# 六十四卦今本／帛本／上博／阜陽／清華出土材料卦名異寫總表

## 一、總說

本表以今本《周易》六十四卦為基準，向外對照：

1. **今本《周易》**
2. **馬王堆帛書《周易》**
3. **上海博物館藏戰國楚竹書《周易》**
4. **阜陽漢簡《周易》**
5. **清華簡（四）《筮法》《別卦》**

並補列部分《歸藏》材料，以便辨析「同卦異名」的早期傳承現象。

需要特別注意：

> **「異寫」不等於「異卦」。**

同一卦在不同材料中可能因通假、異體、音近、字形演變或命名取字不同，而使用不同文字。

# 四、八個基本卦的異名系統

這一組尤其重要，因為它不是單純六十四卦中的個別異文，而直接涉及**八卦名稱系統**。

| 今本八卦 | 帛書名稱     | 字義／字形研究              |
| ---- | -------- | -------------------- |
| 乾    | **鍵**    | 「鍵」與乾的關係，是帛本最醒目的卦名異寫 |
| 坤    | **川**    | 「川」作坤，與今本名稱差異最大之一    |
| 艮    | **根**    | 根／艮音近，並可能涉及卦名來源問題    |
| 兌    | **奪**    | 奪／兌音近                |
| 坎    | **贛／習贛** | 帛本特有的重要異名            |
| 離    | **羅**    | 羅／離音近                |
| 震    | **辰**    | 辰／震音近                |
| 巽    | **筭**    | 筭／巽音近                |

因此帛本不是只存在：

> 乾→鍵、坤→川

兩個異名。

而是形成完整的：

> **乾→鍵
> 坤→川
> 艮→根
> 兌→奪
> 坎→贛
> 離→羅
> 震→辰
> 巽→筭**

這構成一套相對完整的早期八卦命名系統。

馬王堆《繫辭》也直接保存了「鍵（乾）、川（坤）」的寫法，例如「天尊地卑，鍵川定矣」「鍵道成男，川道成女」等，說明這不是整理者偶然替換的文字，而是帛書自身穩定的術語系統。

# 五、六十四卦中最有學術價值的三種「異名」類型

## A. 通假／異體型

這一類最容易處理。

例如：

> 無妄 → 無孟 → 亡忘 → 無亡 → 亡孟

復旦研究指出，這類差異很多可以歸入通假或字形差異；因此不能一看到「名稱不同」就認定是不同卦。

代表：

* 無妄／無孟／亡忘
* 小過／少過
* 大畜／大蓄
* 履／禮
* 復／覆
* 井／丼／汬

---

## B. 同一卦可能有不同「命名取字」

這一類更重要。

例如：

### 震卦

今本作：

> **震**

但《清華簡（四）》保存了「來」字系統。

其原因可能不是單純「震＝來」的通假，而是：

> 同一卦的卦爻辭中同時存在「震」與「來」等高頻字詞，早期命名時可能曾有不同取字。

復旦研究以震卦為例，指出今本卦爻辭中「震」與「來」都非常突出，因此「震」與「來」可能反映卦名形成過程中的不同命名選擇。

---

## C. 「卦名異稱」保存了另一條文本傳承

最值得注意的例子：

### 姤 → 系

今本：

> **姤**

清華簡：

> 「系」

而「系」正好出現在姤卦初六：

> 系于金柅……

因此「姤—系」不宜只看成普通通假；它可能保存了**同一卦在命名階段曾以不同中心詞命名**的痕跡。

同理：

### 豫 → 介

今本：

> **豫**

清華簡及《歸藏》材料：

> **介**

而豫卦六二正有：

> 介于石……

因此「豫—介」也是非常值得研究的案例。

# 六、帛本與今本的最大差異：不只是「字不同」

真正重要的是三個層次同時改變：

### 第一層：卦名

今本：

> 乾、坤、艮、兌、坎、離、震、巽

帛本：

> **鍵、川、根、奪、贛、羅、辰、筭**

### 第二層：六十四卦排列

今本採：

> 乾 → 坤 → 屯 → 蒙 → 需 → 訟 → …… → 既濟 → 未濟

帛本則以八宮式結構排列，八宮依次為：

> **鍵 → 根 → 贛 → 辰 → 川 → 奪 → 羅 → 筭**

其卦序與今本差異極大。帛本六十四卦的排列因此不能直接套入今本《序卦傳》的敘事邏輯。

### 第三層：經傳結構

帛書同時出土《繫辭》等《易傳》材料，例如：

> 「鍵川定矣」

> 「鍵道成男，川道成女」

這表示帛本不只是「今本的異體字版本」，而是保存了另一套《周易》經傳傳承形態。

# 七、今本／帛本／上博／清華的研究定位

可以用下面這張圖作為整個研究的總綱：

**今本《周易》**

→ 固定六十四卦名稱
→ 乾坤開端
→ 上經／下經
→ 《序卦傳》形成敘事性卦序

↓

**帛書《周易》**

→ 鍵／川等早期卦名
→ 八宮式排列
→ 與今本不同的六十四卦次序
→ 保存大量經文異文
→ 同墓出土不同形態《易傳》

↓

**上博簡《周易》**

→ 戰國楚文字系統
→ 部分卦保存
→ 可見「尨、帀、亡忘、欽、繲」等異寫
→ 其復原研究認為殘簡排列基本可與今本六十四卦次序相對應

↓

**清華簡（四）《筮法》《別卦》**

→ 保存八卦／別卦相關材料
→ 出現「亡孟、介、系、來」等特殊卦名
→ 對「同卦異名」問題尤其重要

↓

**阜陽漢簡《周易》**

→ 漢代傳本
→ 可見「肫、帀、伓、林、筮闔、僕、復、登、井、鼎」等異寫
→ 可作為帛本與今本之間的重要比較材料

## 九、目前可以確立的研究結論

### 1. 今本不是唯一的早期卦名系統

「鍵、川、根、奪、贛、羅、辰、筭」顯示，帛本保存了一套完整的八卦異名系統。

### 2. 「同卦異名」不是單一原因造成

至少可以區分：

> **通假／異體**

與

> **不同命名取字**

以及少數：

> **傳抄訛誤**

復旦研究正是以這三類現象作為分析框架。

### 3. 出土材料不是單純用來「校正今本錯字」

更重要的是：

> **它們讓我們看到《周易》卦名本身可能經歷過形成、競爭、淘汰與定型的歷史。**

### 4. 帛本與今本的差異具有「系統性」

不只是：

> 「乾寫成鍵、坤寫成川。」

而是：

> **卦名系統不同＋卦序系統不同＋經文異文不同＋易傳材料不同。**

因此，馬王堆帛書應被視為研究《周易》文本形成史的**獨立重要傳承證據**。

### 5. 上博、阜陽、清華的價值在於「交叉驗證」

尤其值得注意的是：

> **帛本所見某些異名，如果能在戰國上博簡、戰國清華簡或漢代阜陽簡中找到平行材料，就不再只是「帛書特殊寫法」，而可能反映更早或更廣泛的《易》文本傳統。**

這正是下一階段研究的核心。
