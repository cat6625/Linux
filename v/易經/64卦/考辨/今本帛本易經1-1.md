# 今本《周易》與馬王堆帛書《周易》比較學術筆記

## 一、核心定位：兩種《周易》文本系統

馬王堆帛書《周易》的重要性，不只在於保存了一批與今本不同的文字，而在於它使我們能夠看到：**今本《周易》所呈現的六十四卦結構，並非漢代以前唯一存在的文本形態。**

今本與帛本可以從四個層面比較：

| 層面     | 傳世今本         | 馬王堆帛本              |
| ------ | ------------ | ------------------ |
| 卦名文字   | 乾、坤等         | 鍵、川等大量異字           |
| 六十四卦排列 | 乾坤起首，分上下經    | 不以乾坤為開端，呈現另一套排列系統  |
| 經文面貌   | 經傳長期傳抄後的定型文本 | 保存漢初所見的另一傳本形態      |
| 易學思想   | 後世經傳解釋影響深    | 同時保存較早的經文形態與漢初易學思想 |

因此，帛本最重要的價值不是「取代今本」，而是讓今本重新獲得一個**歷史比較坐標**。

---

# 二、乾坤：今本的「首卦」與帛本的「異名」

## 1. 今本：乾坤構成《周易》開篇

今本以：

> 乾 → 坤

作為六十四卦開端。

這使乾坤具有特殊的結構地位：

* 乾：天、剛健、創始
* 坤：地、柔順、承載
* 乾坤形成天地、陰陽的基本對偶
* 後世《易傳》進一步把乾坤提升為《易》的天地之門

因此，在今本系統中，**乾坤不只是兩個卦，而是整部《周易》的宇宙論起點。**

## 2. 帛本：乾作「鍵」、坤作「川」

馬王堆帛本最醒目的特徵之一，是卦名文字不同。

今本：

> 乾、坤

帛本：

> 鍵、川（巛）

這使「乾坤」問題出現另一個重要層次：

> **卦名本身也存在歷史性的文字傳承。**

「鍵」所保存的，是以「健」義理解乾卦的一條重要線索；而「川／巛」則呈現坤卦名稱的另一種古文字面貌。

因此研究乾坤時，不宜只問：

> 「乾到底是什麼意思？」

還應問：

> **「乾／鍵」這個卦名，在不同時期究竟以什麼文字、什麼語音、什麼語義系統被理解？」**

---

# 三、乾卦：今本「乾乾」與帛本「鍵鍵」

今本乾卦九三：

> 君子終日乾乾，夕惕若，厲，無咎。

帛本相應文字作「鍵鍵」。

這個差異非常具有代表性。

### 今本系統

「乾乾」後來可以與《彖傳》《象傳》《文言》中的「天行健」互相連結，因此乾卦逐漸被理解為：

> 剛健 → 自強 → 君子進德 → 天道運行

### 帛本系統

「鍵」字則直接保存了「健」這一語義聯想。

因此兩本比較的價值，在於看到：

> **乾卦的「剛健」義並不是後世突然創造，而是可以在帛本的卦名及異文中找到早期文本層面的線索。**

---

# 四、坤卦：從「地」到「承載、順應」

坤卦同樣呈現兩套文本傳承。

今本初六：

> 履霜，堅冰至。

帛本有相應異文。

無論具體異字如何解釋，這條卦辭在兩種傳統中都保留了同一個重要結構：

> 微小徵兆 → 陰氣發展 → 結果逐漸形成

因此坤卦與乾卦形成鮮明互補：

| 乾    | 坤    |
| ---- | ---- |
| 剛健   | 柔順   |
| 發動   | 承載   |
| 向外展開 | 向內蓄積 |
| 天    | 地    |
| 創始   | 成受   |
| 動    | 順時而動 |

這也是後來乾坤陰陽哲學的重要基礎。

---

# 五、真正重要的差異：六十四卦卦序

如果只比較「乾／鍵、坤／川」，其實還沒有觸及帛本最重要的價值。

真正具有結構性意義的，是：

> **帛本六十四卦並不是按照今本乾坤起首、上下經的方式排列。**

## 今本卦序

今本採：

> 乾 → 坤 → 屯 → 蒙 → 需 → 訟……

形成「上經—下經」的整體結構。

而《序卦傳》又對這個次序進行哲學化說明，例如：

> 有天地，然後萬物生焉……

因此今本卦序具有很強的**宇宙生成、事物發展與人事秩序**色彩。

---

# 六、帛本卦序：另一套「八宮式」結構

帛本則呈現另一種高度規整的排列方式。

其重要特徵可以概括為：

> **以八個經卦作為大的組織單位，再在各組中排列八個別卦。**

其中八個經卦形成：

### 陽性系統

> 鍵（乾）
> 根（艮）
> 贛（坎）
> 辰（震）

### 陰性系統

> 川（坤）
> 奪（兌）
> 羅（離）
> 筭（巽）

這一排列最值得注意的是：

> **帛本不是單純把六十四卦重新排列，而是把六十四卦放入一個「經卦—別卦」的矩陣結構中。**

所以今本與帛本的差別，可以簡化為：

> **今本較像「敘事型卦序」；帛本較像「分類型卦序」。**

---

# 七、今本與帛本卦序的思想差異

可以用下面這個表作為核心比較：

|      | 今本          | 帛本              |
| ---- | ----------- | --------------- |
| 基本形式 | 上下經         | 六十四卦整體排列        |
| 開端   | 乾、坤         | 不以乾坤作唯一開端       |
| 組織方式 | 卦與卦的次序關係    | 經卦與別卦的矩陣關係      |
| 思想特色 | 天地—萬物—人事的發展 | 陰陽分類與卦體配列       |
| 後世解釋 | 《序卦傳》尤其重要   | 八宮、陰陽、納甲等系統可作比較 |
| 研究價值 | 保存成熟的傳世系統   | 顯示另一種早期卦序傳統     |

因此：

> **今本卦序回答的是「為什麼這一卦接著那一卦」；帛本卦序更值得問的是「六十四卦如何被分類、排列與計算」。**

---

# 八、帛本卦序與陰陽、五行、納甲

帛本的排列又可以與漢代流行的陰陽、五行及納甲思想放在一起觀察。

尤其值得注意的是八個經卦的陰陽分組，以及乾坤、艮兌、坎離、震巽等對偶關係。

可以形成：

> 乾／坤
> 艮／兌
> 坎／離
> 震／巽

這與八卦彼此對待的思想具有高度關聯。

另一方面，漢代易學又發展出：

> 八卦 → 天干 → 五行 → 方位 → 陰陽

的複合系統。

因此研究帛本時，可以把它看成：

> **六十四卦文本 + 八卦分類 + 陰陽配對 + 漢代數術思想**

所形成的一個複合型易學世界。

但最穩妥的表述是：

> **帛本卦序與漢代陰陽五行、納甲思想具有可比較的結構關係，而不宜簡化為「帛本卦序就是納甲表」。**

---

# 九、卦名異文：帛本真正提供的第二條線索

帛本的重要性還在於大量卦名異文。

可以建立一張「今本—帛本」對照表：

| 今本 | 帛本  | 可觀察方向         |
| -- | --- | ------------- |
| 乾  | 鍵   | 健、剛健義         |
| 坤  | 川／巛 | 地、承載系統        |
| 否  | 婦   | 卦名傳承與語義問題     |
| 咸  | 欽   | 感應與敬畏的語義聯想    |
| 謙  | 兼   | 兼容、包容與謙義      |
| 履  | 禮   | 行履與禮制的關聯      |
| 大畜 | 大毒  | 蓄積、養育、制約等語義問題 |
| 革  | 勒   | 改變、約束、整頓等語義聯想 |

這些異名的最大價值，不一定是證明「帛本比今本更原始」，而是：

> **讓我們看見同一卦名在不同易學傳統中可能存在不同的命名、讀法與理解。**

---

# 十、經文層：帛本保存另一種《周易》面貌

帛本與今本的比較，還應從卦名深入到卦爻辭。

例如乾卦：

> 今本「乾乾」
> 帛本「鍵鍵」

坤卦：

> 今本「貞」等字
> 帛本部分位置可見「正」等異文

這些差異使研究者能夠觀察：

1. 戰國至秦漢文字的傳抄現象
2. 通假字與異體字
3. 古文字與後世隸書系統的轉換
4. 某些核心術語的早期語義
5. 《周易》經文在漢初的實際流傳形態

因此帛本的價值可以概括為：

> **它不是另一部《易經》，而是《周易》歷史傳承中的另一個重要文本證據。**

---

# 十一、經與傳：帛本最大的思想價值

馬王堆帛書並不只保存《六十四卦》經文，還保存了重要的《易傳》材料，例如：

> 《二三子問》
> 《繫辭》類文獻
> 《衷》
> 《要》
> 《易之義》等

這使我們可以同時觀察：

> **「經」如何被保存，以及「傳」如何解釋經。**

其中尤其重要的是「德義」問題。

---

# 十二、從卜筮到德義：帛本《易傳》的重要思想

帛書《易傳》所呈現的孔子形象，不是單純反對卜筮，而是：

> **承認《易》原有卜筮功能，同時把閱讀《易》的目的轉向德義。**

《要》所呈現的思想尤其重要：

> 卜筮可以使用，但君子真正應觀察的是「德」與「義」。

因此可以形成：

### 巫史之易

> 問吉凶 → 求神明 → 知命

### 君子之易

> 觀卦象 → 察時勢 → 修德義 → 求無咎

這裡產生了一個重要思想轉變：

> **《易》沒有被從卜筮中完全切割出去，而是在保留卜筮傳統的同時，被重新解釋為君子修身、政治實踐與理解天道變化的工具。**

---

# 十三、「命」與「德」：帛本易學的人事核心

帛書《易傳》尤其重視：

> 命、時、德、義、損益

這幾個概念。

其基本思想可以整理成：

> **天命決定處境，德行決定人在處境中的作為。**

所以乾卦：

> 潛龍勿用

不是單純「不能做事」，而是：

> 時機未至 → 蓄德 → 待時。

而：

> 亢龍有悔

則是：

> 位極 → 不知退 → 德不足以承其位 → 產生悔患。

因此乾卦在帛書《易傳》中可以被理解為一套：

> **「時—位—德—行」的政治與人格哲學。**

---

# 十四、坤卦的政治哲學：柔不是弱

坤卦則提供另一條路：

> 柔順 → 承載 → 順時 → 成事

因此「坤」不是消極退讓。

真正的核心是：

> **順勢而動，而不是被動不動。**

這使乾坤形成互補：

> 乾：主動而知退
> 坤：柔順而能承

最後形成：

> **剛健與柔順並非對立，而是天地運行的兩種基本力量。**

---

# 十五、今本與帛本的「經傳關係」

兩者最大的學術價值之一，是讓我們看到《周易》不是一次完成的作品，而是一個長期形成的文本系統。

可以畫成：

**早期卜筮經文**

↓

**不同地域、時代的傳抄本**

↓

**不同卦名、異文、卦序傳統**

↓

**戰國至秦漢易學解釋**

↓

**帛本所保存的一條傳承**

與

**今本所保存的另一條傳承**

因此：

> 今本不是唯一的《周易》歷史形態；帛本也不是簡單的「改良版今本」。

兩者共同構成我們重建《周易》形成史的重要材料。

---

# 十六、帛本《易傳》與五帝—聖王傳統

帛書《易傳》還把《易》與：

> 黃帝
> 神農
> 堯
> 舜

等聖王傳統聯繫起來。

其中重要觀念是：

> **聖人觀象 → 制器 → 利天下**

也就是：

> 八卦不是純粹抽象符號，而可以被轉化為制度、器物與政治秩序。

例如乾坤與：

> 衣裳、上下、秩序

相聯繫。

這使「乾坤」不只是宇宙論：

> 天／地

也成為：

> 上／下
> 君／臣
> 尊／卑
> 制度／秩序

的思想來源。

因此帛書《易傳》中的《易》，已經具有非常鮮明的：

> **政治哲學與制度文明意義。**

---

# 十七、特殊卦辭與歷史記憶

帛本研究還提供另一個重要方向：

> **六十四卦是否保存了某些古代歷史事件、社會生活與傳說記憶？**

例如：

### 旅卦

「喪牛於易」可以與古代「有易」地名及王亥傳說聯繫研究。

如此一來，「旅」就不一定只能理解成抽象的人生旅行，也可能保存：

> 商族遠行、貿易、牛群、異族交往與死亡

等古代社會記憶。

### 革卦

「革」又可以與：

> 改制、政權變動、軍事整頓、革命

等歷史語境聯繫。

因此：

> **卦爻辭可能同時具有占筮語言、社會生活語言與歷史記憶三個層次。**

---

# 十八、今本與帛本最值得建立的總體模型

最後可以把兩種文本濃縮成下面這張圖：

```text
                    《周易》
                       │
             ┌─────────┴─────────┐
             │                   │
          傳世今本             馬王堆帛本
             │                   │
       乾 → 坤起首          不以乾坤起首
             │                   │
         上、下經              另一卦序
             │                   │
        《序卦》解釋        經卦／別卦結構
             │                   │
       天地生成敘事          陰陽分類系統
             │                   │
        經傳定型化          異卦名、異文保存
             │                   │
        後世易學主流          漢初易學面貌
             │                   │
             └─────────┬─────────┘
                       │
                 《易》形成史
                       │
        ┌──────────────┼──────────────┐
        │              │              │
       卜筮           義理           政治
        │              │              │
       吉凶           德義           聖王
        │              │              │
       命              修身           制度
                       │
                   損益之道
                       │
              「知命」而不「任命」
```

# 十九、最後的學術結論

如果要用一句話概括今本與帛本的關係，我會寫成：

> **今本《周易》保存了乾坤開篇、上下經及經傳結構逐漸定型後的主流文本；馬王堆帛書則保存了另一套六十四卦排列、卦名及經文異文，並同時保存了戰國秦漢之際易學由卜筮向德義、政治與宇宙論轉化的重要思想材料。**

更進一步說：

> **今本讓我們看到「後來的《周易》是什麼樣子」；帛本則讓我們看到「《周易》在漢初還可能是什麼樣子」。**

所以今後研究乾坤、卦序及卦名演變時，最適合採取的不是「今本正、帛本異」的比較方式，而是：

> **今本＝一條成熟傳承線**
> **帛本＝另一條早期傳承線**
> **兩者互證＝重建《周易》文本形成史。**
