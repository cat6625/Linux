《周易》讀書筆記修訂稿（第三版）  
18 蠱 → 19 臨 → 20 觀 → 21 噬嗑  
——經文、十翼次層與漢魏象數的分層考證  
**一、 研究定位、選題邊界與分層體系**  
本稿將傳世本第 18 至 21 卦（蠱、臨、觀、噬嗑）設為研究單元，係因應通行本經學傳播史所形成的既有文本組塊，而非主張西周原始文本即存在此四卦的連續哲學生成鏈（馬王堆帛書《六十四卦》異於通行本的卦序即證明序列具有後設性）。  
為擺脫「名為歷史分層，實則沿襲玄學理路」的困境，本稿建立「五層七階」考證體系：

> * **第一層：西周經文與古代物象**（結合甲骨文、金文、西周宗法與刑罰史料）。  
> * **第二層：《十翼》次層細分**：  
  * **2a. 《彖傳》**：卦體結構、爻位應與與陰陽升降學。  
  * **2b. 《大象傳》**：先王／君子之社會制度擬構與政治倫理學。  
  * **2c. 《序卦傳》**：戰國至漢初對卦序的後設哲學串聯。  
> * **第三層：漢魏象數與義理經學**（虞翻卦變模型、王弼玄學注釋）。  
> * **第四層：漢代卦氣與消息曆法**（十二消息卦、曆法對應）。  
> * **第五層：宋代形式化卦變圖式**（圖書之學與幾何/形式推演）。

**二、 第一層考證：西周社會史、古文字與出土文獻**  
**18 蠱卦：宗法承繼與鬼神祟害**

> * **古文字與卜辭**：甲骨卜辭常見「疾蠱」（如「貞兄丙蠱」），指因祖先祟害、鬼神致禍或腹內蟲疾所引起的異常病態。  
> * **宗法制度**：「幹父之蠱」「幹母之蠱」之「幹」，字本通「榦」（築牆之木），引申為框正、修補與承擔。在西周宗法制度下，此非單純腹中蟲或巫蠱，而是指承擔並糾正父祖輩所留下的政事失誤、權責虧欠或宗法秩序危機。  
> * **政令程序**：「先甲三日，後甲三日」係西周發布政令、實施祭祀前的準備與復查程序（甲日為旬首），與漢代納甲術數無關。

**19 臨卦：金文物象與監臨制度**

> * **古文字物象**：金文「臨」字象人自上俯視皿中或下界之形，核心物象為「以上監下、俯察視導」。  
> * **西周制度**：指涉西周貴族或官僚對地方、族群進行監臨、督察與治理的政治行為，非抽象的哲學概念。

**20 觀卦：宗廟祼禮與視聽權威**

> * **宗廟禮制**：「盥而不薦，有孚顒若」為西周宗廟祭祀的核心環節。「盥」（或祼禮，以香酒灌地降神、洗手潔淨）是祭祀中神聖感與凝聚力最強烈的階段；「薦」則是隨後獻上具體牲醴饌具的程序。  
> * **出土異文**：帛書《六十四卦》作「觀」，楚竹書《周易》亦有相應卦名。經文關注的是禮儀中「示觀」所產生的神聖威嚴，而非日常心理視覺。

**21 噬嗑卦：肉刑制度與獄訟流程**

> * **刑具與肉刑**：爻辭「屨校滅趾」（足械／木枷限制雙腳）與「何校滅耳」（頸械／枷項損傷頭耳），真實記錄了西周的刑具與肉刑。  
> * **西周司法史**：對照《尚書·呂刑》所載「五刑」（墨、劓、剕、宮、大辟）及西周金文（如《曶鼎》《 \\nmǐ 簋》）中的獄訟銘文，「利用獄」反映了西周審理爭訟、施加刑罰以去除內部阻隔（「頤中有物」）的真實司法制度。

**三、 第二層考證：《十翼》內部的次層解析**  
《十翼》各篇成書背景與學派取向不同，不可混為一談：

| 卦名 | 2a. 《彖傳》（卦體爻位學） | 2b. 《大象傳》（政治倫理學） | 2c. 《序卦傳》（後設串聯） |
| :---- | :---- | :---- | :---- |
| **18 蠱** | 「剛上而柔下，巽而止」：以陰陽爻位變動解卦 | 「君子以振民育德」：轉化為賑濟平民、涵育道德的政教規範 | 「以喜隨人者必有事，故受之以蠱。蠱者，事也。」 |
| **19 臨** | 「剛浸而長……剛中而應」：以陽爻上升、爻位應與解卦 | 「君子以教思無窮，容保民無疆」：轉化為君王容保萬民的治理倫理 | 「有事而後可大，故受之以臨。臨者，大也。」 |
| **20 觀** | 「大觀在上……觀天之神道而四時不忒」：昇華為天道哲學 | 「先王以省方觀民設教」：轉化為巡狩省察、因俗設教的政治制度 | 「物大然後可觀，故受之以觀。」 |
| **21 噬嗑** | 「頤中有物……剛柔分，動而明」：以卦體隔間與動察解卦 | 「先王以明罰敕法」：轉化為整飭法度、明審刑罰的法制倫理 | 「可觀而後有所合，故受之以噬嗑。噬嗑者，合也。」 |

> * **《彖傳》**：專注於卦體陰陽（剛柔、升降、浸長）的構造分析。  
> * **《大象傳》**：具有極強的「先王／君子以……」模式，將物象一律轉化為西周至戰國的儒家政治倫理與制度規範。  
> * **《序卦傳》**：建立「事 → 大 → 可觀 → 合」的連環因果敘事，屬戰國末至漢初經學家對卦序的後設合理化解釋。

**四、 第三至五層解構：漢魏象數、卦氣與宋易模型**

> * **漢魏象數（第三層）**：虞翻解蠱卦稱「泰初之上而成蠱」「坤上之初」，係基於其預先設定的「母卦變爻」規則進行推演。這是一種內部自洽的解釋工具，不能視為西周經文的歷史生成機制。王弼注《觀》取「觀感化物」，則是魏晉玄學去制度化的義理解讀。  
> * **漢代卦氣（第四層）**：《臨》（剛浸而長、八月有凶）與《觀》在漢代被納入十二消息卦（臨為二月卦，觀為八月卦）。《彖傳》雖有「長消」概念，但成熟的曆法對應係漢儒後加的系統化模型。  
> * **宋代卦變（第五層）**：宋人（如朱熹《卦變圖》）將卦變進一步圖表化與幾何化，屬於符號形式學的建構，距離古經原貌更遠。

**六、 結論**  
傳世本 18 至 21 卦的文本演變歷程，呈現了中國思想史典型的層累特徵：

> 1. **西周源頭**：經文原為西周社會現實的紀錄，涉及宗法秩序修復（蠱）、監臨治理（臨）、宗廟祭祀與神聖示範（觀）、肉刑與獄訟處斷（噬嗑）。  
> 2. **十翼轉譯**：《彖傳》將其解析為卦體陰陽爻位；《大象傳》將其抽象為儒家的政治倫理與法制規範；《序卦傳》則將原本獨立的四卦編織為「事 → 大 → 觀 → 合」的後設哲學鏈條。  
> 3. **後世系統化**：漢魏以來的象數卦變、納甲與消息卦氣，係學者為求體系完備而建立的封閉解釋模型。

研究《周易》必須堅持「先釋經文，再辨傳文；明確分層，不以漢宋倒灌西周」的學術原則，方能還原各歷史層次的原貌。
