# AI 如何「解卦」：從《古筮真詮》到「易起卦」App 的比較框架

> 本文整理 Gemini 對自身解卦方式的說明，並進一步修訂成一套可用來檢驗 AI 六爻解卦品質的分析框架。
>
> 核心問題不是「哪個 AI 算得準」，而是：
>
> **AI 究竟是在依照六爻規則推演，還是在使用六爻術語生成一篇看起來合理的解卦文章？**

---

## 一、Gemini 所提出的三層解卦模型

Gemini 將 AI 解卦概括成三個層次：

1. **符號解析**
2. **典籍規則比對**
3. **語境故事轉譯**

這個框架大方向是合理的，但其中幾個概念需要修正。

---

## 二、第一層：卦象與排盤資料的結構解析

Gemini 原本稱為：

> 「純資料對接（100% 機械對照）」

這個說法太絕對。

如果使用者提供：

- 本卦
- 變卦
- 動爻
- 六親
- 世爻
- 應爻
- 干支
- 月建
- 日辰

AI 確實首先需要將這些資訊解析成可以進一步處理的結構。

但大型語言模型並不是傳統程式中的固定 parser。它仍然是透過語言模式與上下文進行辨識，因此這一層本身就可能出錯。

例如：

- 爻位讀錯
- 初爻、上爻方向混淆
- 本卦與變卦混淆
- 上卦、下卦弄反
- 世應位置判錯
- 六親配置錯誤
- 動爻判錯
- 干支與五行對應錯誤

因此比較精確的名稱應該是：

> **第一層：卦象與排盤資料的結構解析**

而不是「100% 機械對照」。

---

# 三、第二層：六爻規則的選取

Gemini 將這一層稱為：

> 「規則檢索（典籍庫比對）」

這個說法也需要稍微修正。

AI 確實可能根據自身掌握的知識與當前上下文，找到與下列內容相關的規則：

- 《增刪卜易》
- 《卜筮正宗》
- 《古筮真詮》
- 六爻納甲傳統
- 五行生剋
- 月建、日辰
- 世應
- 用神
- 元神、忌神、仇神
- 動爻、變爻
- 三合、六合、沖
- 暗動
- 回頭生、回頭克
- 應期等

但必須注意：

> **AI 知道一個術語，不等於 AI 知道該術語在這一卦中應該如何使用。**

例如：

> 「申子辰三合水局」

AI 可能知道這是一個六爻術語。

但是這不代表它一定能正確判斷：

- 申、子、辰究竟分別是哪三個爻？
- 三者是否同時存在？
- 各自是否具備成立條件？
- 是否有動靜問題？
- 是否受到月建、日辰影響？
- 三合在這個問題中究竟應該作用於什麼？

所以：

> **「知道規則」與「正確執行規則」是兩回事。**

---

# 四、第三層：語境轉譯與故事生成

Gemini 對這一層的自我批評，我認為相當重要。

它稱之為：

> 「故事轉譯」

這確實是 AI 解卦最容易出現問題的地方。

例如卦中出現：

> **官鬼爻**

AI 很容易進一步把它解釋為：

> 規則、限制、壓力、制度、權威……

如果使用者問的是：

> 「我與 AI 的溝通為什麼會出現問題？」

AI 甚至可能進一步產生：

> 「官鬼代表 AI 系統的規則與限制，因此你的 Prompt 受到系統規則約束。」

這句話語意上非常順。

但問題是：

**這是不是《古筮真詮》的實際判卦程序？**

必須另外證明。

---

# 五、最重要的問題：術語映射 ≠ 六爻推演

必須區分以下四種情況：

| 情況 | 性質 |
|---|---|
| 古典六爻文獻明確如此使用 | 古典規則 |
| 《古筮真詮》明確如此判斷 | 現代六爻理論規則 |
| AI 根據傳統象義自行延伸 | AI 推論 |
| AI 把卦象套入現代情境 | 語境故事生成 |

例如：

```text
官鬼
  ↓
規則
  ↓
AI 系統規則
  ↓
Prompt
  ↓
Prompt Engineering
```

這條鏈每一步單獨看似乎都「有道理」。

但整條鏈可能根本不是六爻古筮的判斷程序。

如果沒有文獻依據，那麼它比較接近：

> **六爻術語 + 現代語境故事生成**

而不是嚴格意義上的六爻推演。

---

# 六、Gemini 所說的「過度擬合」

Gemini 自己承認：

> 為了把古代卦理連結到現代問題，犯了「過度擬合（Over-fitting）」的錯。

這個自我批評方向是對的，但如果要描述得更精確，可以稱為：

> **語境過度適配（context overfitting）**

因為這裡真正發生的事情不是典型機器學習意義上的 overfitting，而比較像：

```text
使用者問題
    ↓
尋找卦象中的象徵
    ↓
選擇一個現代對應物
    ↓
把兩者建立敘事關係
    ↓
生成一個語意流暢的解釋
```

例如：

```text
官鬼
→ 規則
→ 系統限制
→ AI
→ Prompt
→ Prompt Engineering
```

如果缺乏六爻原典或《古筮真詮》的明確規則支持，這種推導就屬於：

> **語境聯想，而不是規則推演。**

---

# 七、為什麼不同 AI 會得到不同答案？

Gemini 說：

> 不同 AI，甚至同一個 AI，都可能給出完全不同的答案。

這一點確實符合實際使用經驗。

但原因不能簡化成：

> 「Prompt 語氣不同，所以 AI 切換回答模式。」

真正可能影響結果的因素包括：

```text
卦象解析
    +
所引用的六爻規則
    +
規則的優先順序
    +
對旺衰的理解
    +
對動爻的理解
    +
對變爻的理解
    +
對卦意的理解
    +
使用者問題的語境
    +
模型自身的知識
    +
生成時的不確定性
    ↓
最終答案
```

因此，同一個卦可能出現：

> 第一次：「大吉」

> 第二次：「目前無法判定」

> 第三次：「有利但存在阻礙」

而三次都可能生成一套語氣完整、邏輯表面上連貫的理由。

這正是 LLM 解卦最需要警惕的地方：

> **文章寫得合理，不代表推導過程正確。**

---

# 八、重新建立一個更適合檢驗 AI 的「四層模型」

相比 Gemini 的三層模型，我認為更適合研究六爻 AI 的方式是拆成四層：

```text
第一層：卦象解析
        ↓
第二層：六爻規則選取
        ↓
第三層：規則實際運算
        ↓
第四層：現代語境解釋
```

這四層的重要性並不相同。

## 第一層：資料有沒有讀對？

例如：

- 動爻是哪幾爻？
- 世爻是哪一爻？
- 應爻是哪一爻？
- 六親是否正確？
- 干支是否正確？
- 本卦、變卦是否正確？

---

## 第二層：選了什麼規則？

例如：

- 為什麼取這一爻為用神？
- 為什麼判斷某爻為忌神？
- 為什麼使用三合？
- 為什麼使用暗動？
- 為什麼把某個動爻視為重要？

---

## 第三層：規則到底有沒有正確執行？

這是最重要的一層。

例如 AI 說：

> 「申子辰三合水局，因此用神得力。」

不要先看它的結論。

應該要求它回答：

```text
申是哪一爻？
子是哪一爻？
辰是哪一爻？

三者各自：
- 爻位？
- 六親？
- 五行？
- 動靜？
- 旺衰？

按照你引用的規則：
- 三合成立條件是什麼？
- 本卦是否符合？
- 三合究竟作用於哪個爻？
- 對用神產生什麼作用？
```

這樣就很容易看出 AI 到底是真的在「算」，還是在「講」。

---

# 九、《古筮真詮》為什麼特別適合拿來測 AI？

這與《古筮真詮》的特殊性有關。

它的重要特色之一，就是試圖把傳統六爻判斷整理成比較系統化的規則。

例如可以看到：

```text
用神
 ↓
旺衰
 ↓
月建、日辰
 ↓
動爻
 ↓
變爻
 ↓
生剋制化
 ↓
世應關係
 ↓
卦意
 ↓
應期
```

這樣的系統化，反而非常適合拿來當作 AI 的「監考標準」。

但必須注意：

> 《古筮真詮》本身也是現代六爻理論著作，而不是先秦時代的原始筮法。

因此它可以作為：

> **「現代六爻理論的一套規則基準」**

卻不能直接被當成：

> **「《周易》原始筮法的唯一正確答案」。**

---

# 十、為什麼「易起卦」App 很值得研究？

如果「易起卦」App 的排盤、學習內容與解卦方法確實大量採用《古筮真詮》體系，那麼它就不只是一般的「算卦 App」。

它可以被視為一種：

> **現代六爻理論的軟體實作。**

可以形成如下比較：

```text
《古筮真詮》
      ↓
   六爻規則
      ↓
「易起卦」App
      ↓
固定化／程式化的實作
      ↓
ChatGPT / Gemini
      ↓
自然語言生成與推理
```

這時真正有價值的問題就不是：

> 「哪一個比較準？」

而是：

> **AI 在哪一步開始偏離六爻規則？**

---

# 十一、建議採用「三方對照實驗」

這也是 Gemini 認為值得做的實驗。

對同一個卦，建立三方對照：

### ① AI 原始解卦

只提供必要的卦象資料：

- 本卦
- 變卦
- 動爻
- 世應
- 六親
- 干支
- 月建
- 日辰
- 占問內容

要求 AI 自行解卦。

---

### ② 「易起卦」App

記錄：

- App 的排盤結果
- App 提供的規則
- App 的解釋
- App 是否引用特定卦例
- App 是否使用《古筮真詮》的術語

---

### ③ 原典／古例

進一步查：

- 《增刪卜易》
- 《卜筮正宗》
- 《古筮真詮》
- 其他相關六爻文獻

確認：

> 這個判法究竟來自哪一個傳統？

---

# 十二、不要只比較「最後答案」

這是整個實驗最重要的原則。

不要只記錄：

```text
AI A：吉
AI B：凶
App：吉
```

這樣資訊量非常低。

應該比較：

| 項目 | AI | App | 古例／文獻 |
|---|---|---|---|
| 卦象解析 |  |  |  |
| 世應 |  |  |  |
| 六親 |  |  |  |
| 用神 |  |  |  |
| 旺衰 |  |  |  |
| 月建 |  |  |  |
| 日辰 |  |  |  |
| 動爻 |  |  |  |
| 變爻 |  |  |  |
| 生剋 |  |  |  |
| 三合／六合／沖 |  |  |  |
| 暗動 |  |  |  |
| 卦意 |  |  |  |
| 應期 |  |  |  |
| 最終判斷 |  |  |  |

這樣才能知道：

> **到底是哪一步出現差異。**

---

# 十三、進一步要求 AI 提供「可稽核推導」

如果真的要測試 AI，建議不要問：

> 「這卦吉不吉？」

而是要求：

> **「請按照《古筮真詮》的方法逐步分析，不要使用沒有文獻依據的現代象徵轉譯。每一個重要判斷都指出所使用的規則，並說明該規則如何套用到本卦。」**

然後要求固定輸出：

```text
1. 原始卦資料
2. 六親配置
3. 世應
4. 用神選取
5. 月建、日辰
6. 動爻
7. 變爻
8. 各爻旺衰
9. 生剋制化
10. 特殊結構
11. 卦意分析
12. 應期
13. 最終判斷
14. 所引用的規則
15. 哪些部分屬於推測
```

如此一來，AI 就比較難只靠文筆把漏洞藏在敘述裡。

---

# 十四、這個方法甚至可以檢驗「AI 是否真的懂六爻」

這比問：

> 「ChatGPT 和 Gemini 誰比較會算？」

有意義得多。

因為真正需要測試的不是「答案像不像老師傅」，而是：

### A. 能不能正確讀卦？

### B. 能不能正確選取規則？

### C. 能不能正確執行規則？

### D. 能不能區分「古典規則」與「自己的推論」？

### E. 能不能把規則與現代語境分開？

最後才是：

### F. 能不能把推導結果用人話說清楚？

---

# 十五、與你目前研究「數字卦」的問題其實是一條線

你之前一直在追問：

> **古代「數字卦」究竟是什麼？**

現在又進一步研究：

> **後世六爻究竟是怎麼解卦？**

而現在又出現第三個問題：

> **現代 AI 所謂的「解卦」，究竟是在執行這套規則，還是在模仿解卦文章的語言？**

三個問題可以串成一條研究鏈：

```text
考古材料
   ↓
早期筮占
   ↓
《周易》
   ↓
後世納甲六爻
   ↓
《增刪卜易》等卦例
   ↓
《古筮真詮》的現代規則化
   ↓
「易起卦」App 的軟體實作
   ↓
ChatGPT / Gemini 的 AI 解卦
```

但是：

> **每往下一層，都不能把下一層的理論倒灌回上一層。**

例如：

不能因為現代六爻使用：

> 世應、六親、納甲、五行

就反過來說：

> 商周數字卦也一定是按照現代六爻方式解讀。

同樣地，也不能因為 AI 可以用現代語言解釋：

> 官鬼＝規則

就認為：

> 古代筮者一定把官鬼理解成「AI 系統規則」。

---

# 十六、最後的判準

你最近研究數字卦時一直強調一個很重要的方法：

> **先把材料本身說清楚，再談後世如何解釋它。**

同樣的原則，也應該套用在 AI 解卦：

> **先確認 AI 到底使用了什麼規則，再評價它的結論。**

因此，判斷 AI 解卦能力時，可以用一句話作為核心標準：

> ## **「不要先問它算得準不準，先問它到底是怎麼算出來的。」**

如果 AI 能夠：

1. 正確讀取卦象；
2. 明確指出採用的六爻規則；
3. 正確套用規則；
4. 區分原典內容與自己的推論；
5. 不把現代故事硬套回古代術語；
6. 最後才將結果轉譯成現代語言；

那才比較接近：

> **「依規則解卦」。**

反過來，如果 AI 的主要流程是：

```text
卦象
 ↓
抓幾個熟悉的六爻術語
 ↓
與使用者問題建立象徵聯想
 ↓
寫出一篇流暢的故事
 ↓
補上一個吉凶結論
```

那麼即使文章寫得非常漂亮，也只能說：

> **它很會寫「像解卦的文章」。**

而不能據此證明：

> **它真的按照六爻規則完成了推演。**

---

## 一句話總結

> **《古筮真詮》提供的是一套可以被拆解、檢查的現代六爻規則體系；「易起卦」App 可以視為這類規則的軟體化實作；而 ChatGPT、Gemini 等 LLM 則必須另外證明自己是否真的執行了這些規則，而不是僅僅生成一篇使用六爻術語、符合使用者語境的解卦文章。**

這也是「AI 解卦」真正值得研究的地方。
